# 020 전처리 스도코드

## 목적
`020.주제별 텍스트 일상 대화 데이터`를 SFT용 canonical parquet row로 만들고 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "020.주제별 텍스트 일상 대화 데이터"`
2. `data_usage = "SFT"`
3. `system = "당신은 일상 대화 상대입니다. 사용자의 말에 자연스럽고 친근하게 반응하세요."`
4. 입력 경로는 `data/korean_raw/020.주제별 텍스트 일상 대화 데이터/01.데이터/**/*.json`

## parquet 생성 규칙
1. `info[*]`를 row 단위로 처리한다.
2. `split_key`는 `info.id` 우선, 없으면 `file_path + info_index`다.
3. `annotations.speaker_type == "1:1"`인 row만 사용한다.
4. turn은 `annotations.lines[*]`를 사용한다.
5. turn text는 `norm_text` 우선, 없으면 `text`를 쓰고 `"1 : "` 같은 접두어를 제거한다.
6. 빈 turn text는 제외한다.
7. 처음 등장한 `speaker.id`를 user, 다음 다른 `speaker.id`를 assistant로 둔다.
8. 세 번째 화자가 나오면 row 전체를 제외한다.
9. 연속 같은 화자 turn은 공백 하나로 병합한다.
10. 마지막 turn이 user면 마지막 user turn 하나를 제거한다.
11. assistant turn이 하나도 없으면 제외한다.
12. `messages = [system, user, assistant, ...]`
13. `content`는 system 제외 user/assistant text를 공백 하나로 이어 붙인다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. source별 Lance dataset으로 저장한다.

## 품질 이벤트
- non 1:1 speaker_type
- `annotations.lines` 누락
- third speaker
- empty turn
- final assistant missing
