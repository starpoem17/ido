# 141 전처리 스도코드

## 목적
`141.한국어 멀티세션 대화`의 parquet 생성과 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "141.한국어 멀티세션 대화"`
2. `data_usage = "SFT"`
3. `base_system = "당신은 사용자의 대화 상대로서 친절하고 긍정적으로 반응합니다."`
4. 입력 경로는 `data/korean_raw/141.한국어 멀티세션 대화/01-1.정식개방데이터/**/*.json`

## parquet 생성 규칙
1. `sessionInfo[*]`를 session row 단위로 처리한다.
2. `split_key`는 `sessionID` 우선, 없으면 `file_path + session_index`다.
3. `speaker1 -> user`, `speaker2 -> assistant`
4. `dialog[*].utterance`를 strip한다.
5. 빈 utterance가 있으면 session 전체를 제외한다.
6. 시작 role이 user가 아니면 제외한다.
7. role 교대가 깨지면 제외한다.
8. 마지막 user turn은 하나만 제거한다.
9. 마지막 보정 후 assistant turn이 없으면 제외한다.
10. `personaInfo.clInfo.personaFeatures`의 유효 문자열을 원순서대로 모은다.
11. 유효 feature가 있으면 `base_system + "\n[clInfo persona]\n" + join(features, "\n")`를 system으로 쓴다.
12. 없으면 `base_system`만 사용한다.
13. `messages = [system, user, assistant, ...]`
14. `content`는 system 제외 user/assistant text를 공백 하나로 이어 붙인다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. source별 Lance dataset으로 저장한다.

## 품질 이벤트
- `sessionInfo` 누락
- empty utterance
- bad start role
- bad alternation
- final assistant missing
- empty persona feature
