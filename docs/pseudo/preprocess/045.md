# 045 전처리 스도코드

## 목적
`045.지식검색 대화`의 parquet 생성과 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "045.지식검색 대화"`
2. `data_usage = "SFT"`
3. `system = "user의 질문에 대해서 텍스트 근거 기반으로 대답을 하는 전문가야"`
4. 입력 경로는 `data/korean_raw/045.지식검색 대화/01-1.정식개방데이터/**/*.json`

## parquet 생성 규칙
1. 원본 JSON row 하나를 parquet row 하나로 본다.
2. `split_key`는 원본 id 우선, 없으면 `file_path + row_index`다.
3. `utterances`에서 `질문자 -> user`, `전문가 -> assistant`로 읽는다.
4. 문자열은 모두 strip한다.
5. `reference_text[*].value`가 있으면 user 문장은 `질문자 text + "\n근거: " + concat(reference)`로 만든다.
6. 없으면 질문자 text만 user로 사용한다.
7. assistant는 항상 전문가 text를 사용한다.
8. `messages = [system, user, assistant, ...]`
9. `content`는 system 제외 user/assistant text를 공백 하나로 이어 붙인다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. source별 Lance dataset으로 저장한다.

## 품질 이벤트
- `utterances` 누락
- empty user text
- empty assistant text
- malformed reference_text
