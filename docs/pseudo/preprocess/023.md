# 023 전처리 스도코드

## 목적
`023.국회 회의록 기반 지식검색 데이터`의 parquet 생성과 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "023.국회 회의록 기반 지식검색 데이터"`
2. `data_usage = "SFT"`
3. `system = "당신은 국회회의록 기반으로 대답을 하는 위원이야. 질문에 대해서 사실 근거에 기반해서 대답해줘."`
4. 입력 경로는 `data/korean_raw/023.국회 회의록 기반 지식검색 데이터/3.개방데이터/1.데이터/**/*.json`

## parquet 생성 규칙
1. 원본 JSON row 하나를 parquet row 하나로 본다.
2. `split_key`는 원본 id 우선, 없으면 `file_path + row_index`다.
3. `context`, `question.comment`, `answer.comment`를 strip한다.
4. 셋 중 핵심 필드가 비면 row를 제외한다.
5. `content = context`
6. `messages = [system, user(question.comment), assistant(answer.comment)]`
7. `context_learn`, `context_summary(summary_q, summary_a)`는 사용하지 않는다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. source별 Lance dataset으로 저장한다.

## 품질 이벤트
- 파일 파싱 실패
- empty context
- empty question
- empty answer
