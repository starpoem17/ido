# 019 전처리 스도코드

## 목적
`019.법률, 규정 (판결서, 약관 등) 텍스트 분석 데이터`를 PT용 canonical parquet row로 만들고 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "019.법률, 규정 (판결서, 약관 등) 텍스트 분석 데이터"`
2. `data_usage = "PT"`
3. `messages = null`
4. 입력 경로는 `data/korean_raw/019.법률, 규정 (판결서, 약관 등) 텍스트 분석 데이터/01.데이터/**/*.json`

## parquet 생성 규칙
1. 원본 JSON row 하나를 parquet row 하나로 본다.
2. `split_key`는 원본 id 우선, 없으면 `file_path + row_index`를 사용한다.
3. 아래 필드를 순서대로 읽어 유효 문자열을 수집한다.
   - `mentionedItems.rqestObjet`
   - `disposal.disposalcontent`
   - `assrs.dedatAssrs`
   - `facts.bsisFacts`
   - `dcss.courtDcss`
   - `close.cnclsns`
   - `clauseArticle`
   - `comProvision`
4. 각 필드는 배열일 때만 사용하고 문자열 원소만 strip 후 사용한다.
5. 유효 문자열을 줄바꿈 하나로 이어 `content`를 만든다.
6. 유효 문자열이 하나도 없으면 row를 제외한다.
7. `skip_field`, `skip_item`은 fixup 로그로 남긴다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. PT-only dataset Lance로 저장한다.

## 품질 이벤트
- 파일 파싱 실패
- 비배열 필드
- empty content
- fixup skip_field / skip_item
