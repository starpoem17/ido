# 국립국어원 신문 말뭉치 2020 전처리 스도코드

## 목적
`국립국어원 신문 말뭉치 2020`을 PT용 canonical parquet row로 만들고 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "국립국어원 신문 말뭉치 2020"`
2. `data_usage = "PT"`
3. `messages = null`
4. 입력 경로는 `data/korean_raw/국립국어원 신문 말뭉치 2020/*.json`

## parquet 생성 규칙
1. `document[*]`를 row 단위로 처리한다.
2. `split_key`는 `document.id` 우선, 없으면 `file_path + document_index`다.
3. `document.paragraph[*].form`의 유효 문자열을 순서대로 수집한다.
4. 첫 번째 유효 문단을 제목으로 사용한다.
5. 남은 유효 문단을 줄바꿈 하나로 이어 본문을 만든다.
6. 제목만 있고 본문이 없으면 제외한다.
7. `content = "제목: " + title + "\n내용: " + body`

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. PT-only Lance dataset으로 저장한다.

## 품질 이벤트
- missing paragraph
- empty title
- empty body
