# 030 전처리 스도코드

## 목적
`030.웹데이터 기반 한국어 말뭉치 데이터`를 PT용 canonical parquet row로 만들고 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "030.웹데이터 기반 한국어 말뭉치 데이터"`
2. `data_usage = "PT"`
3. `messages = null`
4. 입력 경로는 `data/korean_raw/030.웹데이터 기반 한국어 말뭉치 데이터/01.데이터/**/*.json`

## parquet 생성 규칙
1. `named_entity[*]`의 각 요소를 row 단위로 처리한다.
2. `split_key`는 `file_path + entity_index`를 사용한다.
3. `named_entity.title.sentence`를 제목으로 읽는다.
4. `named_entity.content.sentence`들을 strip 후 공백 하나로 이어 본문을 만든다.
5. 제목이 비면 제외한다.
6. 본문 문장이 모두 비면 제외한다.
7. `content = title + "\n" + body`

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. PT-only Lance dataset으로 저장한다.

## 품질 이벤트
- `named_entity` 누락
- empty title
- empty body
