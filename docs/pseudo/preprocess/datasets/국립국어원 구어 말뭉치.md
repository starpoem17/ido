# 국립국어원 구어 말뭉치 전처리 스도코드

## 목적
`국립국어원 구어 말뭉치`를 PT용 canonical parquet row로 만들고 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "국립국어원 구어 말뭉치"`
2. `data_usage = "PT"`
3. `messages = null`
4. 입력 경로는 `data/korean_raw/국립국어원 구어 말뭉치/*.json`

## parquet 생성 규칙
1. `document[*]`를 row 단위로 처리한다.
2. `split_key`는 `document.id` 우선, 없으면 `file_path + document_index`다.
3. `document.utterance[*].form`을 strip 후 수집한다.
4. 유효 발화가 하나도 없으면 제외한다.
5. 유효 발화를 줄바꿈 하나로 이어 `content`를 만든다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. PT-only Lance dataset으로 저장한다.

## 품질 이벤트
- `document` 누락
- `utterance` 누락
- empty utterance form
