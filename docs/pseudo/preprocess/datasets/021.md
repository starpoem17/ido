# 021 전처리 스도코드

## 목적
`021.용도별 목적대화 데이터`를 canonical parquet row로 만들고 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "021.용도별 목적대화 데이터"`
2. `data_usage = "SFT"`
3. `system = "당신은 콜센터 상담원입니다. 사용자의 문의에 정확하고 친절하게 답변하세요."`
4. 입력 경로는 `data/korean_raw/021.용도별 목적대화 데이터/01.데이터/**/*.json`

## parquet 생성 규칙
1. `info[*]`를 row 단위로 처리한다.
2. `split_key`는 `info.id` 우선, 없으면 `file_path + info_index`다.
3. `annotations.text`를 PT용 `content` 후보로 읽는다.
4. `annotations.text`가 비면 row를 제외한다.
5. FT turn은 `annotations.lines[*]`를 사용한다.
6. `speaker.id == "B"`는 user, `speaker.id == "A"`는 assistant다.
7. 첫 번째 assistant(`A`) turn 하나를 제거한 뒤 대화를 시작한다.
8. 제거 후 첫 turn이 user가 아니면 row를 제외한다.
9. turn text는 `norm_text` 우선, 없으면 `text`를 사용하고 화자 접두어를 제거한다.
10. 빈 turn text는 제외한다.
11. 연속 같은 화자 turn은 공백 하나로 병합한다.
12. 마지막 turn이 user면 마지막 user turn 하나를 제거한다.
13. assistant turn이 하나도 없으면 제외한다.
14. `messages = [system, user, assistant, ...]`
15. `content`는 `annotations.text`를 사용한다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. source별 Lance dataset으로 저장한다.

## 품질 이벤트
- empty annotations.text
- `annotations.lines` 누락
- bad start after first A removal
- empty turn
- final assistant missing
