# 011 전처리 스도코드

## 목적
`011.일상대화 한국어 멀티세션 데이터`의 parquet 생성과 dataset별 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "011.일상대화 한국어 멀티세션 데이터"`
2. `data_usage = "SFT"`
3. `system = "당신은 사용자의 대화 상대로서 친절하고 긍정적으로 반응합니다."`
4. 입력 경로는 `data/korean_raw/011.일상대화 한국어 멀티세션 데이터/3.개방데이터/1.데이터/**/*.json`

## parquet 생성 규칙
1. `sessionInfo[*]`를 session row 단위로 순회한다.
2. `split_key`는 `sessionID` 우선, 없으면 `file_path + session_index`다.
3. `dialog[*].utterance`를 strip한다.
4. `speaker1 -> user`, `speaker2 -> assistant`
5. 빈 utterance가 있으면 session 전체를 제외한다.
6. 시작 role이 user가 아니면 제외한다.
7. role 교대가 깨지면 제외한다.
8. 마지막 user turn은 하나만 제거한다.
9. assistant turn이 없으면 제외한다.
10. `messages = [system, user, assistant, ...]`
11. `content`는 system 제외 발화를 공백 하나로 이어 붙인다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 필터링한다.
2. 공통 업로드 절차로 `token_count`를 채운다.
3. source별 Lance dataset 하나로 저장한다.

## 품질 이벤트
- 파일 파싱 실패
- `sessionInfo` 누락
- 빈 utterance
- bad start role
- bad alternation
- final assistant missing
