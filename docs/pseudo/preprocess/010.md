# 010 전처리 스도코드

## 목적
`010.전문분야_사회과학_한국어 멀티세션 데이터`의 parquet 생성과 dataset별 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "010.전문분야_사회과학_한국어 멀티세션 데이터"`
2. `data_usage = "SFT"`
3. `system = "당신은 사회과학 전문 비서입니다. 사용자의 질문에 친절하고 과학적으로 대답합니다."`
4. 입력 경로는 `data/korean_raw/010.전문분야_사회과학_한국어 멀티세션 데이터/3.개방데이터/1.데이터/**/*.json`

## parquet 생성 규칙
1. `sessionInfo[*]`를 session row 단위로 처리한다.
2. `split_key`는 `sessionID` 우선, 없으면 `file_path + session_index`다.
3. `dialog[*].utterance`를 strip한다.
4. `speaker1 -> user`, `speaker2 -> assistant`
5. 빈 utterance, bad start role, role 교대 오류는 session 전체 제외
6. 마지막 user turn은 하나만 제거한다.
7. assistant turn이 남지 않으면 제외한다.
8. `messages = [system, user, assistant, ...]`
9. `content`는 system 제외 발화를 공백 하나로 이어 붙인다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. 공통 업로드 절차로 `token_count`를 `content` 기준으로 채운다.
3. source별 Lance dataset 디렉터리 하나로 저장한다.

## 품질 이벤트
- 파일 파싱 실패
- `sessionInfo` 누락
- 빈 utterance
- bad start role
- bad alternation
- final assistant missing
