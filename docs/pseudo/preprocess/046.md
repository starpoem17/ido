# 046 전처리 스도코드

## 목적
`046.공감형 대화`의 parquet 생성과 Lance 업로드 규칙을 적는다.

## 고정값
1. `source = "046.공감형 대화"`
2. `data_usage = "SFT"`
3. 입력 경로는 `data/korean_raw/046.공감형 대화/01-1.정식개방데이터/**/*.json`

## parquet 생성 규칙
1. 원본 JSON row 하나를 parquet row 하나로 본다.
2. `split_key`는 원본 id 우선, 없으면 `file_path + row_index`다.
3. `utterances`에서 `speaker -> user`, `listener -> assistant`
4. `text`를 strip하고 빈 turn은 제외한다.
5. 시작 role이 user가 아니면 row를 제외한다.
6. role 교대가 깨지면 제외한다.
7. 마지막 user turn은 하나만 제거한다.
8. 마지막 보정 후 assistant turn이 없으면 제외한다.
9. `system = info.situation + "에 대해서 " + join(info.listener_behavior, ", ") + "에 맞추어서 대답을 해주는 친구가 되어줘"`
10. `messages = [system, user, assistant, ...]`
11. `content`는 system 제외 user/assistant text를 공백 하나로 이어 붙인다.

## Lance 업로드 규칙
1. minhash dedup 완료 parquet에서 이 source row만 읽는다.
2. `content` 기준 `token_count`를 채운다.
3. source별 Lance dataset으로 저장한다.

## 품질 이벤트
- `utterances` 누락
- empty turn
- bad start role
- bad alternation
- final assistant missing
