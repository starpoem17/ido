모델이 사용자의 감정 발화에 공감적으로 답변하는 패턴을 학습할 수 있도록 하는 데이터
원본 JSON 한 건이 행 하나의 단위가 된다.
`utterances`에서 role이 `speaker`이면 user, `listener`이면 assistant로 매핑한다.
`speaker`의 `text`는 user query, `listener`의 `text`는 assistant 답변으로 사용한다.
문자열 필드는 모두 처음과 끝 공백을 strip하여 수집한다.
Training은 train, Validation은 val로 매핑한다.

system 생성 규칙
`info.situation` + "에 대해서 " + `info.listener_behavior`(배열을 ", "로 join) + "에 맞추어서 대답을 해주는 친구가 되어줘" 형식으로 생성한다.
ex)
`공공도서관에서 책을 빌렸다.에 대해서 조언, 격려, 동조, 위로에 맞추어서 대답을 해주는 친구가 되어줘`

정규화 규칙
`utterances`가 배열이 아니면 해당 레코드는 제외한다.
`role`이 `speaker` 또는 `listener`가 아니면 해당 turn은 제외한다.
`text`가 문자열이 아니거나 strip 후 빈 문자열이면 해당 turn은 제외한다.
정규화 후 turn이 비어 있으면 해당 레코드는 제외한다.
시작 role이 user가 아니면 해당 레코드는 제외한다.
role 교대(user/assistant)가 깨지면 해당 레코드는 제외한다.
마지막 턴이 user면 마지막 user 턴만 제거하고 레코드는 유지한다.
마지막 user 제거 후 assistant 턴이 1개도 없으면 해당 레코드는 제외한다.

행 생성 규칙
data_type은 "dialog"를 사용한다.
messages는 [system, user, assistant, ...] 구조로 저장한다.
messages[0]의 system은 위의 system 생성 규칙을 사용한다.
content는 system을 제외한 user/assistant text를 원순서대로 이어 붙여 저장한다.
content concat 시 구분자는 단일 공백(" ")을 사용한다.
`info.evaluation`, `listener_empathy`, `speaker_changeEmotion`, `votes`는 기본 학습 입력에서 사용하지 않는다.
