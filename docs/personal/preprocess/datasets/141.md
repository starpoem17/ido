모델이 사용자 발화를 이해하고 자연스럽게 응답하는 패턴을 학습할 수 있도록 하는 데이터
speaker1이 user, speaker2가 assistant 역할이다
`sessionInfo` 안의 각 session(`sessionInfo[*]`)이 행 하나의 단위가 된다
`dialog[*].utterance`는 문자열 처음과 끝의 공백을 strip하여 수집한다
Training은 train, Validation은 val로 매핑한다

정규화 규칙
빈 문자열 utterance가 하나라도 있으면 해당 session은 제외한다.
시작 role이 user가 아니면 해당 session은 제외한다.
role 교대(user/assistant)가 깨지면 해당 session은 제외한다.
마지막 턴이 user면 마지막 user 턴만 제거하고 session은 유지한다.
마지막 user 제거 후 assistant 턴이 1개도 없으면 해당 session은 제외한다.

행 생성 규칙
data_type은 "dialog"를 사용한다.
data_usage는 "SFT"를 사용한다.
messages는 [system, user, assistant, ...] 구조로 저장한다.
content는 system을 제외한 user/assistant utterance를 원순서대로 이어 붙여 저장한다.
content concat 시 구분자는 단일 공백(" ")을 사용한다.
FT에서는 system.content에 `personaInfo.clInfo.personaFeatures`를 추가한다.
clInfo의 feature 순서는 원본 순서를 유지하며, 줄바꿈(`\n`)으로 구분해 붙인다.
topicInfo, summary, date/time은 기본 학습 입력에서 사용하지 않는다.
