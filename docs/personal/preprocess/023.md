모델이 국회 회의록 문맥을 기반으로 질문에 사실 근거 중심으로 답변하는 패턴을 학습할 수 있도록 하는 데이터
원본 JSON 한 건이 행 하나의 단위가 된다.
PT용 텍스트는 `context`를 사용한다.
FT용 대화는 `question.comment`를 user, `answer.comment`를 assistant로 사용한다.
system에는 고정 문구 `"당신은 국회회의록 기반으로 대답을 하는 위원이야. 질문에 대해서 사실 근거에 기반해서 대답해줘."`를 넣는다.
문자열 필드는 모두 처음과 끝 공백을 strip하여 수집한다.

ex)
{
    "data_type" : "dialog",
    "source" : "023.국회 회의록 기반 지식검색 데이터",
    "split" : "train",
    "content" : "대학혁신 지원사업 이건 오랫동안 등록금 동결이 13년째 이어져 오면서 대학 재정이 어려우니까 ...",
    "messages" : [
        {"role" : "system", "content" : "당신은 국회회의록 기반으로 대답을 하는 위원이야. 질문에 대해서 사실 근거에 기반해서 대답해줘."},
        {"role" : "user", "content" : "또 하나 아까 실장님 말씀을 하실 때 이건 1주기 사업 과정에서 발생한 문제이기 때문에 2주기 사업에 선정된 대학에 대해서는 예산 지원을 중단하는 거 이건 좀 어렵다 이렇게 말씀을 하셨는데 맞습니까?"},
        {"role" : "assistant", "content" : "직접 적용을 해 가지고 하기는 어렵다는 말씀인데, 지금 제가 조금 말씀드려도 되겠습니까? 그러면 부대의견 주신 게 저희가 고려하고 있는 사항들입니다. 말씀 주신 대로 부적절하게 지출한 대학에 대해서 점검해 가지고 사업비 환수 등에 필요한 조치 ..."}
    ],
    "token_count" : 123
}

PT 시에는 row의 `content`를 그대로 사용한다.

FT 시에는 row의 `messages`를 직렬화해 사용한다. 직렬화 시에는 `<|system|>`, `<|user|>`, `<|assistant|>` 특수 토큰을 붙인다.

`context_learn`과 `context_summary(summary_q, summary_a)`는 기본 규칙에서는 사용하지 않는다.
