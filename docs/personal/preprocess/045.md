모델이 사용자의 질문에 텍스트 근거 기반으로 답변하는 패턴을 학습할 수 있도록 하는 데이터
원본 JSON 한 건이 행 하나의 단위가 된다.
`utterances`에서 role이 `질문자`이면 user, `전문가`이면 assistant로 매핑한다.
assistant는 항상 `전문가`의 `text`를 사용한다.
system에는 고정 문구 `"user의 질문에 대해서 텍스트 근거 기반으로 대답을 하는 전문가야"`를 넣는다.
문자열 필드는 모두 처음과 끝 공백을 strip하여 수집한다.
Training은 train, Validation은 val로 매핑한다.

user 생성 규칙
`reference_text`가 있으면 질문자의 `text`에 근거 텍스트를 함께 붙인다.
근거 텍스트는 `reference_text[*].value`를 원순서대로 공백 하나로 concat하여 사용한다.
최종 user 문장은 `질문자 text + "\n근거: " + reference_text value concat` 형식으로 만든다.
`reference_text`가 null이거나 유효 `value`가 없으면 질문자의 `text`만 user로 사용한다.

행 생성 규칙
data_type은 "dialog"를 사용한다.
messages는 [system, user, assistant, ...] 구조로 저장한다.
content는 FT용 데이터 구분 없이 system을 제외한 user/assistant text를 원순서대로 이어 붙여 저장한다.
content concat 시 구분자는 단일 공백(" ")을 사용한다.
`search_URL`, `search_query`, `reference_date`, `info.evaluation`, `votes`는 기본 학습 입력에서 사용하지 않는다.
