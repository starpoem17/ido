모델이 사용자의 질문에 대답하는 패턴을 학습할 수 있도록 하는 데이터
speaker1이 사용자
speaker2가 assistant
speaker1의 sessionInfo.dialog.utterance가 user 쿼리, speaker2의 sessionInfo.dialog.utterance가 assistant의 대답
sessionInfo.dialog.utterance는 문자열 처음과 끝의 공백을 strip하여 수집한다
sessioninfo.dialog 하나가 행 하나의 단위가 된다.

PT 시에는 content 안의 내용을 사용하여 causal masking을 적용한 사전학습
content 안의 string은 sessionInfo.dialog.utterance 문장의 양쪽 끝 공백을 strip한 다음 " "으로 구분하여 concat한 것으로 한다.

FT 시에는 system, user, assistant 특수토큰을 붙여서 생성한다. 여기에서 어텐션 마스킹은 일반적인 causal masking을 적용하고 추가로 label ignore를 적용할 예정이다. 특수 토큰과 <|user|>문은 모델의 예측 대상이 아니다. 오직 <|assistant|> 뒤의 문장에 대해서만 역전파가 진행되도록 한다.
