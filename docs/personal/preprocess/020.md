모델이 일상 대화 맥락에서 자연스럽게 응답하는 패턴을 학습할 수 있도록 하는 데이터
원본 JSON의 `info[*]` 항목 하나가 행 하나의 단위가 된다.
`annotations.lines[*]`를 대화 turn으로 사용한다.
문자열 필드는 모두 처음과 끝 공백을 strip하여 수집한다.
Training은 train, Validation은 val로 매핑한다.

turn text 생성 규칙
`norm_text`가 문자열이면 `norm_text`를 우선 사용한다.
`norm_text`가 없으면 `text`를 사용하되 `"1 : "` 같은 화자 접두어는 제거한다.
둘 다 없거나 빈 문자열이면 해당 turn은 제외한다.

user/assistant 구성 규칙
`speaker_type`이 `"1:1"`인 레코드만 사용한다.
turn 순서대로 처음 등장한 `speaker.id`를 user, 다음으로 등장한 다른 `speaker.id`를 assistant로 매핑한다.
세 번째 화자가 나오면 해당 레코드는 제외한다.
연속으로 같은 화자 turn이 나오면 하나의 turn으로 병합한다(구분자는 공백 `" "`).
최종 turn이 user면 마지막 user turn을 제거한다.
최종적으로 assistant turn이 하나도 없으면 레코드를 제외한다.

행 생성 규칙
data_type은 "dialog"를 사용한다.
system에는 고정 문구 `"당신은 일상 대화 상대입니다. 사용자의 말에 자연스럽고 친근하게 반응하세요."`를 넣는다.
messages는 [system, user, assistant, ...] 구조로 저장한다.
content는 system을 제외한 user/assistant text를 원순서대로 이어 붙여 저장한다.
content concat 시 구분자는 단일 공백(" ")을 사용한다.
`annotations.text`, `speechAct`, `morpheme`, 화자 성별/나이 등 메타정보는 기본 학습 입력에서 사용하지 않는다.

ex)
{
    "source" : "020.주제별 텍스트 일상 대화 데이터",
    "split" : "train",
    "content" : "너는 싫어하는 음식 있어? 나는 번데기 싫어해 징그러 그래 그거는 호불호가 가리는 음식긴 하지!",
    "messages" : [
        {"role" : "system", "content" : "당신은 일상 대화 상대입니다. 사용자의 말에 자연스럽고 친근하게 반응하세요."},
        {"role" : "user", "content" : "너는 싫어하는 음식 있어?"},
        {"role" : "assistant", "content" : "나는 번데기 싫어해 징그러"},
        {"role" : "user", "content" : "그래 그거는 호불호가 가리는 음식긴 하지!"},
        ... 이후 반복
    ],
    "token_count" : 123
}

PT 시에는 row의 content를 그대로 사용한다.
FT 시에는 row의 messages를 직렬화해 사용한다. 직렬화 시에는 <|system|>, <|user|>, <|assistant|> 특수 토큰을 붙인다.
