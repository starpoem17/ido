speaker1이 사용자
speaker2가 assistant
speaker1의 utterance가 user 쿼리, speaker2의 utterance가 assistant의 대답
utterance는 문자열 처음과 끝의 공백을 strip하여 수집한다
sessioninfo 안의 dialog 하나가 행 하나의 단위가 된다.
