모델이 목적 대화 맥락에서 문의-응답 패턴을 학습할 수 있도록 하는 데이터
원본 JSON의 `info[*]` 항목 하나가 행 하나의 단위가 된다.
문자열 필드는 모두 처음과 끝 공백을 strip하여 수집한다.
Training은 train, Validation은 val로 매핑한다.

PT 생성 규칙
PT용 텍스트는 `annotations.text`를 그대로 사용한다.
`annotations.text`가 없거나 빈 문자열이면 해당 레코드는 제외한다.

FT 구성 규칙
`annotations.lines[*]`를 turn으로 사용한다.
role 매핑은 `speaker.id == "B"`를 user, `speaker.id == "A"`를 assistant로 둔다.
첫 번째 `A` 발화(인사 멘트)는 FT에서 제외한다.
즉, `lines`에서 첫 `A` turn 하나를 제거한 뒤 남은 대화를 FT로 구성한다.
제거 후 첫 turn은 반드시 `B(user)`여야 하며 아니면 해당 레코드는 제외한다.
연속으로 같은 화자 turn이 나오면 하나의 turn으로 병합한다(구분자 공백 `" "`).
마지막 turn이 user면 마지막 user turn 하나를 제거한다.
최종적으로 assistant turn이 하나도 없으면 해당 레코드를 제외한다.

turn text 생성 규칙
`norm_text`가 문자열이면 `norm_text`를 우선 사용한다.
`norm_text`가 없으면 `text`를 사용한다.
`text`를 사용할 때는 `"A."`, `"B."`, `"A :"`, `"B : "` 같은 화자 접두어를 제거한다.
최종 turn text가 빈 문자열이면 해당 turn은 제외한다.

행 생성 규칙
system에는 고정 문구 `"당신은 콜센터 상담원입니다. 사용자의 문의에 정확하고 친절하게 답변하세요."`를 넣는다.
messages는 [system, user, assistant, ...] 구조로 저장한다.
`speechAct`, `morpheme`, 화자 성별/나이, `annotations.subject`는 기본 학습 입력에서 사용하지 않는다.
